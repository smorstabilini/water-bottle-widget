💧 Acqua / Water

How much your water bottle should weigh at every moment, so you finish your daily target by a set time. Built as a Scriptable widget for iPhone — this page is the installer and a browser version of the same table.

Source on GitHub →

Put it on your iPhone

  1. Install Scriptable from the App Store (free).
  2. Copy the script with the button below (or open the raw file and share it to Scriptable).
  3. In Scriptable tap +, paste, then rename the script to Acqua.
  4. Long-press the home screen → + → Scriptable → add a Small or Medium widget → Edit Widget → set Script to Acqua.
Open raw file

Latest version: … — the script shows its own version in the menu title and the table header, so you can tell if yours is current.

Auto-update

Once installed, the script checks this repository once a day and updates itself from main. Network is only used for that check — offline, it keeps working with the version already on the phone. Turn it off by setting autoUpdate to false in the settings file.
